# GoldenDataset/private

このディレクトリの内容（この README を除く）は `.gitignore` 対象。
実在の作品名・著者名を含むファイル名サンプルをここに置く [MT-28]。

CI は `../public/` のみを実行する [B-14]。ここにあるデータセットはローカルで
`swift test` を実行するときの追加検証、およびパーサの品質向上に使う。

形式は `../public/README.md` と同じ（`docs/Specifications/16_テスト戦略.md`
§16.2 参照）。

## 収集について（フェーズ 0 の未着手項目）

`docs/Specifications/17_実装ロードマップ.md` の 0-3 は「手持ちのファイル名
500 件以上をここに蓄積する」ことを求めている。これは実データが前提のため、
このセッションでは着手していない。着手する際は:

- 実際に所有しているファイルのファイル名一覧（フォルダ構成込み）を用意する
- `expected` 欄は現在の実装結果ではなく、人間が正しいと判断した値を書く
- 誤判定が実運用で見つかったら、都度ここに追加してから実装を直す [MT-25]

## 作り方

```sh
swift Scripts/extract-golden-corpus.swift          # 登録済みライブラリ → corpus/
QOO_REGENERATE_GOLDEN=1 swift test --filter PrivateGoldenGenerator
```

1. `Scripts/extract-golden-corpus.swift` が登録済みのライブラリ／テンポラリを
   走査し、**ファイル名と相対パスだけ**を `corpus/<表示名>.json` へ書き出す。
   ファイルの中身には触れない。
2. `PrivateGoldenGeneratorTests` がコーパスの各ファイル名をプリセットで解析し、
   `real-<ライブラリ名>.json` を作る。

**public と違い、期待値は現在の実装結果を初期値としている** [GT-03]。実データの
正解は人間にしか判定できないため、生成物を人が確認して確定させる。確定するまでは
「回帰の基準線」として使う——パーサを変えたときに実ファイル名 2,346 件の解釈が
変わったことを検出できる。

## 実データでの適合率（2026-08 時点）

| ライブラリ | プリセット | 一致率 |
|---|---|---|
| 成年コミック | 成年コミック(A) | 396/396（100%）|
| 同人誌 | 同人誌(A) | 1803/1804（99.9%）|
| 同人CG | 同人CG(B) | **0/146（0%）** |

同人誌の 1 件は閉じ括弧が欠けたファイル名（`(x) [x (x) x (x)`）。実コーパスでは
`(` 5,953 に対し `)` 5,950 で、閉じ忘れが実在する。照合失敗として扱うのが正しい。

**同人CG が 0% なのはプリセットと実データの食い違い**であって、パーサの不具合では
ない。実ファイルは `(同人CG集) [...]` で始まるが、プリセットのライブラリタイプ名は
`同人CG` で、`@librarytype` の型条件（既知のライブラリタイプ名のいずれか [TY-01]）を
満たさない。**同人誌も、先頭の `(同人誌)` を `@labelgroup1`（イベント）が拾っており、
1,803 件すべてに「イベント: 同人誌」という無意味なラベルが付く。**どちらも
テンプレート定義の見直しで解決する（CLAUDE.md に記録）。
