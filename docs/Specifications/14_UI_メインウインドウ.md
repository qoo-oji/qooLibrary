### ピン留め [PN-01〜PN-06]

```pseudo
visibleLabels(group, selection, expanded):
    pinned = group.labels.filter(isPinned && !isArchived)
    checked = group.labels.filter { selection[group.id]?.contains($0.id) == true }
    if expanded: return すべて（スクロール + インクリメンタル検索）      # [PN-05]
    if pinned.isNotEmpty: base = pinned                               # [PN-02]
    else:                 base = group.labels.sortedByName().prefix(10)  # [PN-03]
    return (base ∪ checked).sortedByName()                            # [PN-06]
```
