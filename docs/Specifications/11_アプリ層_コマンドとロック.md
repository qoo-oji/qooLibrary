## 11.1 Command [A-03][UD-01]

```swift
public protocol Command: Sendable {
    var id: UUID { get }
    /// Undo メニューに出す説明。「12 件のファイルを保管庫に移す」 [UD-06]
    var displayName: String { get }
    var isUndoable: Bool { get }              // false = 完全削除等 [UD-10]
    var affectedFolderIDs: Set<UUID> { get }  // ロック対象の決定に使う [LK-10]

    func execute(_ ctx: CommandContext) async throws -> CommandResult
    func undo(_ ctx: CommandContext) async throws -> UndoResult
    func redo(_ ctx: CommandContext) async throws -> CommandResult
}

public struct CompositeCommand: Command {
    public let children: [any Command]        // [UD-04]
    /// undo は children を逆順に実行する。失敗した子は部分取り消しとして記録 [UD-07]
}

public struct CommandContext: Sendable {
    public let fileOps: FileOperationService
    public let repositories: RepositoryBundle
    public let history: OperationHistoryStore
    public let notifications: NotificationRouter
    public let progress: ProgressReporter?
}

public enum UndoResult: Sendable {
    case complete
    case partial(succeeded: Int, failed: [(item: String, reason: String)])  // [UD-07]
    case impossible(reason: String)
}
```

### Undo 可能な操作 [UD-03]

| Command | 元に戻し方 |
|---|---|
| `MoveFilesCommand` | 逆方向へ move。移動先が変化していれば部分取り消し [UD-07] |
| `CopyFilesCommand` | 生成物を削除 |
| `RenameCommand` / `BulkRenameCommand` / `AutoRenameCommand` / `ConvertRenameCommand` | 逆リネーム（2 パス）[BR-10][CR-52] |
| `TrashCommand` | `TrashReceipt` から復元。失敗時はゴミ箱を開いて手動復元を促す [UD-08][TR-09] |
| `CreateFolderCommand` | フォルダを削除（空でなければ拒否） |
| `CreateAliasCommand` | 生成したエイリアスをゴミ箱へ。**要件定義書のコマンド一覧には無いが、1-9 で追加した UI から呼ばれる変更操作を Undo 対象から漏らさないために実装した** [設計判断] |
| `SetLockedCommand` | ロック状態を戻す。同上。**部分失敗のときは実際に変えられた分だけを戻す**（`items` 全体を対象にすると、触っていない項目のロックまで反転させてしまう）|
| `DeletePermanentlyCommand` | **`isUndoable == false`**。このコードベースで唯一 Undo 不可のコマンドで、Undo スタックへは積まないが操作履歴には残る [UD-10][PD-05]（8章 §8.5）|
| `ArchiveFilesCommand` / `UnarchiveCommand` / `ArchiveFolderCommand` | 逆方向へ移動 + サイドカーも戻す [FA-14][FA-15] |
| `LabelArchiveCommand` | `isArchived` を戻す |
| `AssignLabelCommand` / `UnassignLabelCommand` | `FileLabel` の origin を含めて復元 |
| `CreateLabelCommand` / `DeleteLabelCommand` / `RenameLabelCommand` / `MergeLabelsCommand` | 逆操作。マージは統合前の紐づけを保持して復元 |
| `SetRatingCommand` / `ApplyRatingToSeriesCommand` | 旧値を復元 [RA-06] |
| `SetCoverImageCommand` | 旧参照とキャッシュを復元 |
| `MoveToLibraryCommand` | 逆方向へ移動 + 作成した中間フォルダの削除 [MV-11] |
| `ImportJSONCommand` | インポート前スナップショットから復元 [IE-13][IE-12] |
| `CompressCommand` / `ExtractCommand` | 生成物を削除。元ファイルは不変なので対称性が保たれる [UD-09] |
| `ApplyTemplateDiffCommand` | 差分適用前の設定を復元 [LT-16] |
| `DeleteDuplicatesCommand` | ゴミ箱からの復元（完全削除を選んだ場合は Undo 不可）[DU-28] |

**Undo 不可**: `DeletePermanentlyCommand` [FM-14][UD-10]。

## 11.3 LockManager [5.6 節]

```swift
public actor LockManager {
    public static let shared = LockManager()          // アプリ全体で単一 [LK-11]

    public struct Token: Sendable { let ids: [UUID]; let processName: String }

    /// 待機しない。取得できなければ即座に失敗する [LK-14][LK-15]
    public func tryAcquire(_ folderIDs: Set<UUID>, processName: String) -> Result<Token, LockError>
    public func release(_ token: Token)
    public func isLocked(_ folderID: UUID) -> Bool
    public var activeProcesses: [ActiveProcess] { get }   // ステータスバー表示 [LK-25]
}
```

```pseudo
tryAcquire(folderIDs, processName):
    # デッドロック防止: 取得順序を UUID 昇順に固定 [LK-12][LK-13]
    sorted = folderIDs.sorted()
    for id in sorted:
        if held.contains(id):
            return .failure(.busy(target: nameOf(id), processName: held[id].processName))
    for id in sorted: held[id] = (processName, Date())
    return .success(Token(sorted, processName))
```

### 処理の分類 [LK-01][LK-02]

| 分類 | 対象 |
|---|---|
| **排他** | 一括リネーム [12.3]、変換リネーム [12.5]、ライブラリへの一括移動 [12.4]、保管庫への一括移動・復元、JSON インポート、スキーマ移行、自動リネームの一括適用 [AR2-09] |
| **非排他** | 差分スキャン、フルスキャン、サムネイル・カバー生成、ラベル件数再集計、整合性チェック、ブックフォルダ判定 |

| # | 要件 |
|---|---|
| LK2-01 | ファイルシステムを変更する一括処理のみを排他とする [LK-01] |
| LK2-02 | 単一ファイルへの操作は排他扱いしない [LK-03] |
| LK2-03 | ロックの粒度は登録フォルダ単位。別ライブラリの操作は継続できる [LK-10] |
| LK2-04 | 複数フォルダにまたがる処理は**関係するすべてのロックを取得してから開始する** [LK-12] |
| LK2-05 | 取得順序は UUID 昇順に固定 [LK-13] |
| LK2-06 | 待機・暗黙のキューイングをしない。即座に「別の処理を実行中です」と対象名付きで通知 [LK-14][LK-15] |

### 状態の 3 分類 [ST-20〜ST-27]

/// ① 永続状態 → DB

public final class WindowState {
    public var labelSelection: [UUID: Set<UUID>] = [:]   // [ST-21]
    public var ratingFilter: RatingFilter?
    public var displayMode: DisplayMode = .folder        // [ST-22]
    public var sort: SortDescriptorSpec
    public var listStyle: ListStyle                      // [ST-22] 既定は環境設定「表示」タブの値から読む（実装では `.list`）

    public var paneSplit: PaneSplitState
    public var selection: Set<UUID>
    public var scrollPosition: ScrollPositionState
    public var searchText: String = ""

/// ③ セッション一時状態 → メモリのみ
@Observable
public final class SessionState {
    public var runningProcesses: [ActiveProcess] = []
    public var lockStates: [UUID: LockInfo] = [:]
    // Undo スタックは CommandStack.shared が保持 [UD-11]
}
