# 05. ドメイン層 — 巻数フォーマットとシリーズ抽出

対応要件: SE-01〜SE-33 / CR-20〜CR-25 / RW-06〜RW-10 / 11.3 節

---

## 5.1 巻数フォーマットの記法 [10.2 節]

| メタ記号 | 意味 |
|---|---|
| `??` | 任意桁数の半角数字または全角数字（1 桁以上）。小数点 `.` を含む場合は `3.5` のような小数を許容 |
| `<space>` | 半角スペースまたは全角スペースの **1 個以上**。空白なしにはマッチしない [SE-23][WS-07] |
| それ以外 | リテラル。全角半角の差は `canonicalWidth` を通して吸収する [SE-03] |

```swift
public struct VolumePattern: Sendable, Hashable, Codable, Identifiable {
    public let id: UUID
    public var source: String          // "第??巻" "vol<space>??" "上巻"
    public var isEnabled: Bool
    public var priority: Int           // 登録順＝優先順 [SE-21]
    /// 序列表記のとき、その順序値。数値パターンでは nil。 [SE-10]
    public var ordinalRank: Int?
}

public struct CompiledVolumePattern: Sendable {
    public let id: UUID
    let tokens: [VolumeToken]          // .literal(String) / .digits / .requiredSpace
    public let ordinalRank: Int?
    public var isOrdinal: Bool { ordinalRank != nil }
}
```

```pseudo
compileVolumePattern(source):
    tokens = []
    i = 0
    while i < source.count:
        if source[i...] hasPrefix "??": tokens.append(.digits); i += 2
        elif source[i...] hasPrefix "<space>": tokens.append(.requiredSpace); i += 7
        else: リテラル文字を蓄積
    return CompiledVolumePattern(tokens)
```

## 5.2 巻数の照合

```swift
public enum VolumeMatcher {
    /// 文字列の指定位置から、パターン集合のいずれかに一致する最長の範囲を返す。
    /// @volume の型付き照合 [TY-01][SE-24] と、タイトル末尾からの抽出 [SE-02] の両方で使う。
    public static func matches(in s: Substring,
                               at index: String.Index,
                               patterns: [CompiledVolumePattern]) -> [VolumeMatch]

    /// タイトル末尾に限定した照合。 [SE-02]
    public static func matchAtEnd(_ title: String,
                                  patterns: [CompiledVolumePattern]) -> VolumeMatch?
}

public struct VolumeMatch: Sendable {
    public let patternID: UUID
    public let range: Range<String.Index>
    public let value: VolumeValue
}
```

```pseudo
matchTokens(tokens, s, i):
    for t in tokens:
        switch t:
          case .literal(lit):
              # canonicalWidth 済みで比較 [SE-03]
              if not s[i...].hasPrefix(canonicalWidth(lit)): return nil
              i += lit.count
          case .requiredSpace:
              n = 連続する空白の個数 at i
              if n == 0: return nil                      # [SE-23][WS-07]
              i += n
          case .digits:
              d = 位置 i から連続する数字（全角は半角化して読む）
              if d.isEmpty: return nil
              # "3.5" のように 数字 + "." + 数字 が続く場合は小数として読む
              if s[i+d.count] == "." and 次も数字: d += "." + 続きの数字
              i += 消費した文字数
              captured = Double(d)
    return (endIndex: i, number: captured)
```

| # | 要件 |
|---|---|
| VM2-01 | **末尾に届く一致のうち最長のものを採る。同じ長さなら登録順が先のもの** [SE-21]。<br>**[実装との差異、2026-08]** 当初は「登録順に評価し最初にマッチしたもの」としていたが、それだけでは登録順に対して脆い。§5.4 の既定セットは `??巻` を `第??巻` より先に列挙しており、その順だと `作品 第01巻` が `01巻` と読まれて**シリーズ名が `作品 第` になる**（実測で再現）。実データの一般コミックは 94% が `第??巻` なので実害が大きい。長い方を採ればユーザーがパターンを追加した順番によらず正しく読める。登録順は同点の決着にのみ使う——SE-21 の趣旨はそこにある [設計判断]。回帰テストは `VolumeMatcherTests.robustAgainstRegistrationOrder` |
| VM2-02 | 序列パターン（`上巻` `前編` 等）は `.digits` を含まず、`ordinalRank` を持つ [SE-10] |
| VM2-03 | `総集編??` のように序列 + 数値の混在パターンは `.ordinal` として扱い、数値は `raw` に含めるのみとする [設計判断: 種別を 1 つに定めないと CR-22 の出力書式が破綻するため] |
| VM2-04 | 全角数字は照合時に半角化して数値化する。`raw` には原文を保持する [SE-03] |
| VM2-05 | `@volume` の型条件は「生の数字表記（`01` `3` `3.5`）」＋「登録済み巻数フォーマット」の和集合とする [SE-24] |

## 5.3 シリーズ抽出 [10.1 節]

```swift
public enum SeriesExtractor {
    public struct Output: Sendable {
        public let seriesName: String?     // nil = @series 無効 [SE-07]
        public let volume: VolumeValue
        public let volumeRange: Range<String.Index>?
    }

    /// @series を直接書いていないフォーマットにマッチした場合に呼ぶ。 [SE-02]
    public static func extract(fromTitle title: String,
                               patterns: [CompiledVolumePattern]) -> Output
}
```

```pseudo
extract(title, patterns):
    t = title
    m = matchAtEnd(t, patterns)          # 末尾からの巻数照合 [SE-02]
    if m == nil:
        return Output(seriesName: nil, volume: .none, volumeRange: nil)   # [SE-07]
    series = t[..<m.range.lowerBound]
    series = trimWhitespace(series)      # 末尾の空白を除去 [SE-02]
    if series.isEmpty:
        return Output(seriesName: nil, volume: m.value, volumeRange: m.range)
    return Output(seriesName: series, volume: m.value, volumeRange: m.range)
```

### 直接指定との関係 [RW-06〜RW-10]

| フォーマットの記述 | シリーズ名 | 巻数 | `@title` からの除去 |
|---|---|---|---|
| `@series` あり | `@series` の値をそのまま [SE-02a] | `@volume` があればその値、なければ `.none` | **行わない** [RW-08] |
| `@volume` のみあり | `@title` から `@volume` 相当の表記を除去して導出 [RW-10] | `@volume` の値 | 行わない（`@volume` 相当のみ除去） |
| どちらもなし | `@title` 末尾から巻数を除去して導出 [SE-02] | 抽出した巻数 | 行う |
| `@series` と `@title` の両方 | `@series` の値 | 上に同じ | 行わない。`@title` は独立フィールド [RW-09] |

| # | 要件 |
|---|---|
| SE2-01 | `@series` が無効（nil）の場合、紐づけられたラベルグループへのラベル生成・付与を行わない [SE-08] |
| SE2-02 | 抽出した巻数は `ManagedFile.volumeNumber` / `volumeKind` / `volumeRaw` に保存し、ライブラリ表示モードのソートに使う [SE-09][VM-15] |
| SE2-03 | 巻数フォーマットの変更は既存ファイルへの再適用を促す [AT-04][TY-06] |
| SE2-04 | 編集画面ではサンプルタイトルに対してシリーズ名・巻数の抽出結果をプレビューする [SE-22] |
| SE2-05 | `@title` が存在しないフォーマット（`@series` + `@volume` のみ）では、ライブラリ表示モードの表示名を `seriesTitleCompositionFormat`（既定 `@series @volume`）で合成する [SE-33] |

## 5.4 巻数フォーマットセット [11.3 節]

`Sources/QooKit/Resources/Templates/volume-sets.json` に定義する [MT-02]。
`QooKit` のリソースとして持つことで、テストからも同じ定義を参照できる。

> **列挙順は意味を持つ。**`第??巻` を `??巻` より前に置くこと（VM2-01 の実装は
> 最長一致を優先するので順序に依存しないが、他の実装や将来の変更で順序が効く
> 場面に備えて正しい順で書いておく）。

```jsonc
{
  "sets": {
    "VS-Full": [
      { "source": "第??巻" }, { "source": "??巻" },
      { "source": "_??" }, { "source": "_v??" }, { "source": "_V??" },
      { "source": "v??" }, { "source": "V??" },
      { "source": "vol??" }, { "source": "vol.??" }, { "source": "vol<space>??" },
      { "source": "Vol??" }, { "source": "Vol.??" }, { "source": "Vol<space>??" },
      { "source": "volume??" }, { "source": "volume.??" }, { "source": "volume<space>??" },
      { "source": "Volume??" }, { "source": "Volume.??" }, { "source": "Volume<space>??" },
      { "source": "上巻", "ordinalRank": 1 },
      { "source": "中巻", "ordinalRank": 2 },
      { "source": "下巻", "ordinalRank": 3 },
      { "source": "最終巻", "ordinalRank": 9999 }
    ],
    "VS-Doujin": [
      "…VS-Full から _?? _v?? _V?? v?? V?? を除いたもの…",
      { "source": "前編", "ordinalRank": 1 },
      { "source": "中編", "ordinalRank": 2 },
      { "source": "後編", "ordinalRank": 3 },
```

## 5.5 巻数の出力書式 [CR-20〜CR-25]

変換リネームの出力側で使う。

```swift
public struct VolumeOutputStyle: Sendable, Hashable, Codable, Identifiable {
    public let id: UUID
    public var name: String                    // 名前を付けて共有できる [CR-25]
    public var numericTemplate: String = "第{n}巻"   // {n} が数値プレースホルダ [CR-22]
    public var digits: Int = 2                       // 0 = ゼロ埋めしない [CR-22]
    public var numeralWidth: NumeralWidth = .halfwidth  // 半角／全角 [CR-22]
    public var ordinalTemplate: String = "{s}"          // {s} は原文 [CR-22][CR-23]
    public var noneOutput: String = ""                  // [CR-22]

    public enum NumeralWidth: String, Sendable, Codable { case halfwidth, fullwidth }
}

public enum VolumeFormatter {
    public static func render(_ v: VolumeValue, style: VolumeOutputStyle) -> String
}
```

```pseudo
render(v, style):
    switch v.kind:
      case .none:    return style.noneOutput
      case .ordinal: return style.ordinalTemplate.replacing("{s}", with: v.raw ?? "")
      case .numeric:
          n = v.number!
          s = (n == n.rounded() && n.magnitude < 1e15)
                ? String(Int(n))
                : String(n)                        # 3.5 は "3.5"
          # ゼロ埋めは整数部にのみ適用
          if style.digits > 0:
              intPart, fracPart = split(s, at: ".")
              intPart = intPart.leftPad("0", to: style.digits)
              s = fracPart == nil ? intPart : intPart + "." + fracPart
          if style.numeralWidth == .fullwidth: s = toFullwidthDigits(s)
          return style.numericTemplate.replacing("{n}", with: s)
```

### 変換例（要件 10.3 節の表と一致すること）

| 入力 | 種別 | 書式 | 出力 |
|---|---|---|---|
| `(01)` | numeric 1 | `第{n}巻` / 2 桁 | `第01巻` |
| `(3)` | numeric 3 | `第{n}巻` / 2 桁 | `第03巻` |
| `(vol.12)` | numeric 12 | `第{n}巻` / 2 桁 | `第12巻` |
| `(上巻)` | ordinal | `{s}` | `上巻` |
| `(前編)` | ordinal | `{s}` | `前編` |
| なし | none | `""` | （出力なし。CR-30 で周囲ごと削除） |

| # | 要件 |
|---|---|
| VO-01 | 種別ごとにテンプレートを分ける。`第上巻巻` のような破綻を構造的に防ぐ [CR-23] |
| VO-02 | 出力フォーマットに `第@volume巻` のように固定文字列を直接書くことは構文上許容するが、保存時に警告する [CR-24] |
| VO-03 | `VolumeOutputStyle` は独立エンティティとして保存し、複数ルール・複数テンポラリフォルダから参照できる [CR-25] |
