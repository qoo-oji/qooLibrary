## 7.1 スキーマのバージョン管理 [MG-01〜MG-04]

**v1 の時点から `VersionedSchema` を使う。** 移行対象がなくても `SchemaV1` と空ステージの `SchemaMigrationPlan` をファイルとして用意する。

### 起動シーケンス [MG-10〜MG-13][RB-03][RB-06]

```pseudo
bootstrapStore():
    meta = readStoreMetadata()                  # [MG-03]
    if meta == nil: 新規ストアとして作成 → 完了
    if meta.version > app.expectedVersion:
        abort with .schemaTooNew                # [MG-12] 起動中止
    if meta.version < app.expectedVersion:
        # [MG-10] 移行前に必ずスナップショット + ストア複製
```

### ラベルフィルタの索引 [PF-12][DB-01][LF-08〜LF-10]

```swift
public actor LabelIndex {
    /// ラベル → ファイル ID 集合。起動時に構築し、以後インクリメンタルに更新する。
    private var byLabel: [UUID: Set<PersistentIdentifier>]

    public func rebuild(libraryID: UUID) async
    public func add(file: PersistentIdentifier, label: UUID)
    public func remove(file: PersistentIdentifier, label: UUID)

    /// グループ内 OR × グループ間 AND [LF-08][LF-09][LF-10]
    public func query(_ selection: [UUID: Set<UUID>]) -> Set<PersistentIdentifier>
}
```

```pseudo
query(selection):     # selection: labelGroupID -> selected labelIDs
    if selection.isEmpty: return .all
    var result: Set? = nil
    # 小さい集合から積を取ると速い
    for (_, labelIDs) in selection.sorted(by: 推定サイズ昇順):
        union = labelIDs.reduce(into: Set()) { $0.formUnion(byLabel[$1] ?? []) }
        result = (result == nil) ? union : result!.intersection(union)
        if result!.isEmpty: break
    return result!
```

| # | 要件 |
|---|---|
| FI-01 | まず SwiftData の `Predicate` で表現を試み、表現しきれない場合に `LabelIndex` の集合演算へフォールバックする [DB-01]。T-03 の検証結果で既定を決める |
| FI-02 | フィルタ結果から `.trashed` [TR-02] と `isArchived == true` [LF-13][FA-05] を除外する |
| FI-03 | 5 万件で 500ms 以内 [PF-03] |
| FI-04 | 索引はライブラリ単位で保持し、オフラインのライブラリは構築しない |
