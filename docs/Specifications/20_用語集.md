# 20. 用語集（UI の語彙）

画面に出す語の**正**を 1 か所に集める。新しい文言を書くとき・既存の文言を直す
ときは、この表の語を使う。**同じものを 2 つの語で呼ばない**——このアプリの
文字列カタログはフェーズ 2 の終わりに 1,500 鍵を超え、同じ概念が 2〜3 語で
呼ばれている箇所が 18 種類見つかった（2026-09-07 の点検）。ここに載っていない
概念を UI へ出すときは、先にこの表へ 1 行足す。

判断の基準は 3 つ: **macOS の UI で普通に使われる語か**（Finder・システム設定の
訳語に揃える）／**コミック以外のメディアにも当てはまるか**（本アプリは動画などの
メディアライブラリとしても使う想定）／**動詞・助詞まで含めて 1 通りか**。

## 使う語（正）と、使わない語

| 概念 | 使う語 | 使わない語 | 備考 |
|---|---|---|---|
| フォルダを読んで DB を最新にすること | **スキャン** | 走査・再スキャン（動詞としては「スキャンし直す」）| 環境設定「スキャン」タブ・「定期フルスキャン」が既にこの語 |
| どのファイル名フォーマットにも一致しなかったファイル | **未整理**（のファイル）| 未解決・一致しない・一致せず | §19.6。理由を添えるときは「ファイル名がどのフォーマットにも一致していません」 |
| ラベルを分類する軸 | **フィールド** | グループ・ラベルグループ | 型名も `Field*`。DB の列名だけ `labelGroup` のまま |
| `@booktype` が取り出す値のフィールド | **本の種別** | ブックタイプ | メディア一般へ広げるときは「種別」への改名を検討 |
| 画像だけが入っていて 1 冊として扱うフォルダ | **ブックフォルダ** | 画像フォルダ・1 冊分の画像が入ったフォルダ・1 冊扱い | 解除は「ブックフォルダでなくなった」 |
| 右ペイン | **インスペクタ** | 詳細・詳細情報 | 表示メニュー「インスペクタを表示／隠す」 |
| 自動で取る DB の複製・JSON | **バックアップ** | 控え・スナップショット | 動詞は「作成する」「復元する」。種別は「ライブラリのデータ（JSON）」「データベースの複製」「登録とカバー画像」 |
| 利用者が手で書き出す JSON | **ライブラリのデータ** | メタデータ | 動詞は「書き出す」「読み込む」 |
| ファイルを一覧から外す場所 | **保管庫** | アーカイブ・ラベルの保管庫（廃止済み）| 「保管庫**に**移動」「保管庫から戻す」。名詞形（操作履歴）は「保管庫への移動」 |
| ゴミ箱 | **ゴミ箱に入れる** | ゴミ箱へ移動 | Finder の訳語。戻すのは「元に戻す」（Finder の Put Back）|
| 未整理・提案を一覧から外す | **以後出さない／無視を解除／無視中／無視したものも表示** | 以後無視する・無視をやめる・無視しています | 未整理と提案で同じ 4 語 |
| Undo | **取り消す**（⌘Z）| 元に戻す・戻す | 「元に戻す」はゴミ箱の Put Back 専用 |
| 書き出し・読み込み | **書き出す…／読み込む…**、**CSV に書き出す…** | コピーを保存・エクスポート | |
| 走査で DB に載せること | **取り込む** | — | JSON・テンプレートは「読み込む」、メタデータは「読み取る」。テンポラリの「取り込み」とは区別するため、あちらは「入手したファイル」 |
| 蔵書全体 | **ライブラリ** | 蔵書・カタログ | フォルダツリーのグループ名だけ「ライブラリフォルダ」 |
| 通知履歴・操作履歴の 1 行 | **履歴** | 記録 | 「記録」は「見つからないファイルの記録」（DB の行）専用 |
| 登録 | **登録**（ライブラリとして登録する）| 有効化・有効にする | 「ライブラリとして有効にする…」は旧版から引き継いだ未有効の登録にだけ出る |
| 未整理の行に添えるヒント | **近いフォーマット** | 最も近いフォーマット | インスペクタのラベル幅に合わせた |
| 数え方 | **件**（数）・**項目**（名詞）| 本・冊・蔵書・コミック | メディア一般に当てはまる語。「巻」はシリーズの巻数を指すときだけ |
| 開くアプリ | **ファイルを開くアプリ** | 本を開くアプリ・コミックを開くアプリ・ビューア | 環境設定のタブ名だけ「ビューア」 |
| テンプレート | **テンプレート**（組み込みは「プリセット」）| ブックタイプ定義・ライブラリタイプ | |
| メンテナンスのタブ | **見つからないファイル／保管庫／シリーズの提案** | ファイルの保管庫 | 左ペインの件数は 3 タブとも「N 件」 |

## 表現の作法

- **説明文はですます調で書く**——見出し・カード名・ボタン名・チェックボックスの題・
  操作名は体言止め／動詞句でよいが、**本文（説明・注意・エラーの三要素）に
  である調と体言止めを混ぜない**。同じ画面に並ぶ説明が 1 つだけ「〜する。」
  「〜の置き場。」だと目に付く（2026-09-08、初回セットアップの 3 枚のカードで
  実際にそうなっていた）。
- **操作名（Undo メニュー・操作履歴の「内容」）は名詞形**で書く——「「x」の移動」「ラベル「y」の削除」。動詞形にすると「「x」を移動を取り消す」と読める。
- **全角ダッシュ「——」・「〜そうです」「〜ようです」・括弧付きの補足**は使わない。理由や仕組みの説明はマニュアルへ。
- 文語（控え・雛形・写す・無傷・丸ごと・手がかり・ふだん・かたまり・憶える）と口語（うまくいかなかった・お使い・ご自身）は使わない。
- ボタン名は動詞句 1 つ（「確認済みにする」「書き出す…」）。長い説明をボタンに載せない。
- 「取り消せません」は破壊的な操作の確認ダイアログにだけ書く（ここは説明ではなく警告）。
